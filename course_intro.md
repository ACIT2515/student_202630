# ACIT 2515

## Theme

ACIT2515 is a course about solving problems by programming in Python, including
Object Oriented Programming. It will help you solve problems and automate tasks.

## Goals

1. Learn to organize our thinking when solving problems:
   - Decompose problems into smaller pieces.
   - Combine Data and Actions: Object Orientation
2. Communicate understanding of a problem to others (often our future selves)
3. Specify what we want the computer to do.
4. Verify that the outcome is correct and/or desired
   - Make this automatic - unit testing frameworks.
5. Construct solutions so that they can be changed or adapted.
6. Think and work with a high degree of precision and detail

These skills are thinking skills and transferable outside of the programming
domain.

## Practice / How To Avoid: "Do you even lift bro?"

- The only way to get better at design and programming is to practice.
- Programming includes writing programs ("coding"), and ... reading code,
  designing solutions, testing code, and debugging code. You need to practice
  all of these.
- Try to think of programming like exercise or playing an instrument. You don't
  get fitter by watching videos of other people working out. You have to _do it_
  and practice, all of the different activities.

## AI / LLM's

- Yes, "AI" can write most of the code for this course. You may finish quickly
  and feel competent, but beware of the
  [Dunning-Kruger effect](https://youtu.be/4FGnb2lgPBA?feature=shared).
- Delegating to AI doesn't build programming skills. It's like getting someone
  else to lift weights for you.
- Consistent use of AI results in "Cognitive Debt" - you will get "dumber"
- AI-generated code often requires you to already know the answer to understand or fix it.
- LLM AIs hallucinate (produce incorrect or misleading code).
- [OECD Digital Education Outlook 2026](https://www.oecd.org/content/dam/oecd/en/publications/reports/2026/01/oecd-digital-education-outlook-2026_940e0dd8/062a7394-en.pdf)
  - A growing body of evidence suggests that ... introduction of generative AI
    can create a "mirage of false mastery," where high‑quality, AI‑enabled
    output conceals underlying weaknesses in human skill
  - There is accumulating evidence that increased reliance on GenAI tools can
    suppress students’ engagement in self‑monitoring (defined as the ongoing
    process of checking, regulating, and adjusting one’s understanding and
    strategies during learning), reflection, and evaluative judgement of one’s
    learning processes, processes that are fundamental to autonomous learning
    ...thereby weakening the very skills that underlie deep learning.

## Intelligent Usage

- If you are going to use AI use it as a tutor .
- Turn off AI autocomplete - it will answer before you get a chance to think.
- Review and critique AI-generated code to improve your own coding skills.
- [How to Learn to Program Lex Fridman and thePrimeagen - In light of AI](https://youtu.be/z-U1r4k5r2s?feature=shared&t=205)

## Class Format

- **BEFORE** class:
  - Flipped learning and self-study
    - Practice Coding: Complete Lab that will be taken up next class
    - Review content notes and answer directed reading questions (available on
      the Learning Hub)
- **DURING** class:
  - Review of Lab and Directed Reading Questions (30 Minutes)
  - Design and Programming Demonstration (30 Minutes)
  - Exercise (45 Minutes)
  - Computational Thinking (15 Minutes)
  - Lab Start (30 Minutes)
