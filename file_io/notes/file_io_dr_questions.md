
# Directed Reading Questions

Answer each question in a few sentences.

1. What is a relative file path, and why is it usually better than an absolute
	path in a course project?

1. Why should you use a `with` statement when opening a file? What happens when
	the `with` block finishes?

1. You are adding a new entry to an existing server log. Which file mode should
	you use, `"w"` or `"a"`? What would happen if you used the other mode?
